# Xtags 0.1.9 更新说明

2026-09-27。此版保留六类主意图、三个辅助信号及 0.1.8 的判断问题；主要修复标签对应的帖子、数据传输边界和日常使用可靠性。

- 标签现在只读取主帖正文和作者，不再把引用卡片的文字归到外层作者。折叠长文仍在展开前使用页面中已有的全文；暂时拿不到全文时不分析摘要。
- 排队中的帖子在发送前复查；帖子消失、正文改变或启用“跳过回复”后，失效任务会退出队列。多个标签页仍可共享同一条有效请求。
- 暂时性错误会有限重试，弹窗显示最近一次请求状态并提供手动重试入口。认证、权限和响应格式错误不会自动反复请求。重试可能增加服务商费用。
- 成功响应限制为 64 KiB，只保留必需的判断字段；HTTP 错误正文不显示在网页或诊断信息中。持久缓存改为按条写入，最多 3,000 条、2 MiB。
- 标签适配页面深浅色，可通过键盘聚焦和 Enter/空格查看详情。设置保存失败会恢复已保存的值。“暂停并清空缓存”会在清理后保持暂停，API key 留在本地。

验证：48 项单元测试及 52 项使用临时 Chrome、模拟 API 的 DOM 回归通过。它们覆盖队列取消、全文、引用归属、失败恢复、响应净化、缓存迁移、键盘和设置反馈。测试不包含真实服务商请求，提交前仍需按 [检查清单](PRE_SUBMISSION.md)进行人工验证。
