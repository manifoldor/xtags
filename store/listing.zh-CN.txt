Xtags

使用条件与数据说明
需要自备所选服务的 API key 并连接网络。默认使用 TypeSafe，也支持兼容的自定义 HTTPS API，服务商可能收取费用。明确同意数据传输、配置 key 并启用后，Xtags 会将 X / Twitter 页面上已渲染帖子的正文和作者账号发送给所选服务进行分类，包括可能在视口之外、以及你有权限访问的受保护帖子。折叠的长推文会在你点击展开前，读取 X 页面数据中已有的全文并发送分类。这不是设备端本地分析。

辅助理解帖子的意图
Xtags 在浏览 X 时为帖子添加简洁的 AI 标签，默认通过 TypeSafe 的 Jev 模型估计帖子是告知、说服、挑拨、推销、娱乐，还是其他意图。

另有三个信号：诱导愤怒、未披露推广和机器生成。你可以调整信号的显示阈值，或查看它们的概率。这些信号根据文字线索估计，不核实实际收款、文本来源或帖子中的事实。

按你的习惯调整
• 在弹窗中暂停或继续分类。
• 跳过被识别为回复的帖子。
• 调整三个提示信号的阈值。
• 显示或隐藏状态面板。
• 复用本地分类缓存；“暂停并清空缓存”会停止处理，手动重新启用后才会再次分析。
• 在弹窗查看最近请求状态，必要时手动重试失败的帖子。
• 根据浏览器界面语言自动选择简体中文或英文，也可手动切换。

开始使用
1. 从所选服务商获取 API key，默认服务商为 TypeSafe：https://typesafe.ai
2. 打开 Xtags 弹窗并点击“设置”，保留官方服务，或保存兼容 TypeSafe 的完整 HTTPS API URL 并授权所选域名。更换 URL 会清除 key 并要求重新同意。然后阅读数据说明和隐私政策，勾选同意项并点击“同意并启用”，再填写 key。
3. 启用 Xtags，浏览 X / Twitter。
4. 按需调整阈值和显示设置。

隐私与使用限制
API key、设置及有容量上限的帖子 ID、正文指纹、评分、时间戳缓存保存在浏览器本地。key 仅供扩展可信页面和后台读取，X 页面内容脚本只收到“已配置 key”的状态。开发者不运营分析服务器或统计服务；分类请求直接发送给所选 API，该服务商还会接收 IP 地址等常规连接信息。使用前请阅读关联的隐私政策。

Xtags 分析提取出的帖子文本，不分析图片或视频。回复识别及 AI 分类可能出错。标签不能证实欺骗、文本来源或作者的真实意图。本项目与 X Corp 无关联。
