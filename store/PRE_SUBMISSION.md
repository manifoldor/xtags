## P1：强烈建议同步完善

- [ ] **明确敏感内容范围**：当前扫描页面帖子，不区分公开和受保护帖子，也不是仅当前视口内内容；折叠长文还会读取页面数据中的全文。本地披露已更新；进一步改进是限制不希望外发的内容/提供按次处理方式。不得在文案中写“只处理公开帖子”。
- [ ] **数据最小化**：评估分类是否真的需要作者 handle；如果不需要，删除上传字段并同步修改政策、权限说明和截图。
- [x] **新用户引导**：设置页已加入“获取 TypeSafe API key”链接，并在同意前明确自备 key 和服务商可能收费。
- [x] **误判文案**：同意前展示 AI 判断可能有误的提示；商店详细说明保留同等说明。
- [x] **key 隔离**：Chrome 140+ 下将 `storage.local` 限制为可信扩展上下文；后台仅向内容脚本提供不含 key 的设置快照和 `hasKey` 状态。设置页仍能编辑 key，后台仍用它向所选服务认证。正式送审前仍需在目标 Chrome 环境手工核对访问边界。
- [x] **主页链接**：`manifest.homepage_url` 指向项目 Pages 主页，运行包版本为 0.1.9。
- [x] **删除和停用路径**：设置页“暂停并清空缓存”会暂停、等待后台确认删除，不自动重传；key 保留，可另行清空 key 输入框并移出焦点保存。失败不显示成功。
