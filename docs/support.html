Labels do not appear

  1. Use Chrome 140 or later. Open Settings from the popup, read the data notice, check the acknowledgement and click Agree and enable. TypeSafe is the default service. For a custom compatible API, save its full HTTPS URL and grant host access first, then consent and enter a key issued for that service. Upgrading from a release before 0.1.8 requires renewed consent for full-text processing.
  2. Open an X page containing text posts. Refresh existing pages after installing or updating the extension. For a collapsed long post, Xtags waits for its full text rather than classifying only the preview; it may temporarily show Full text unavailable.
  3. Check Skip replies and the status panel. A 401 error usually indicates an invalid key; provider credits or access may also be required.
  4. Check the latest API status in the popup and use Retry failed posts after correcting the problem. Temporary network/server errors have bounded automatic recovery (at most nine API attempts); authentication errors do not automatically retry. Fixing the saved key also permits retrying.

Stop requests or delete local data

Pause or withdraw consent to stop requests. Pause and clear cache in Settings waits for local judgments to be removed, keeps your API key and leaves processing paused; manually enable it again to resume. Empty the key field and move focus to save the change. Uninstall to remove the extension's local storage. Contact the selected provider for provider-side deletion.

Report an issue

Include the extension and Chrome versions, operating system, selected language, steps to reproduce and a redacted screenshot. Labels are model estimates; a prediction alone does not establish wrongdoing or authorship.
